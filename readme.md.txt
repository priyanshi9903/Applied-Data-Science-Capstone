# Applied Data Science Capstone

This repository contains all notebooks and Python files completed as part of the IBM Applied Data Science Capstone project.

## Project Workflow

1. Data Collection using SpaceX API
2. Data Collection using Web Scraping
3. Data Wrangling
4. Exploratory Data Analysis using SQL
5. Exploratory Data Analysis using Visualization
6. Interactive Visual Analytics with Folium
7. Interactive Dashboard using Plotly Dash
8. Predictive Analysis using Machine Learning
